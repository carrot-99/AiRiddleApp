# データ仕様書

## 1. 問題データ（`AiRiddleApp/Data/Riddle.csv`）

### 書式

- 文字コード UTF-8、改行 LF、**ヘッダー行なし**
- 1行 = 1問、列は 3 つ

| 列 | 内容 | 書き方 |
| --- | --- | --- |
| 1 | 問題文 | 自由。**アプリ内で一意**（重複不可） |
| 2 | AIの答え | `答え。解説…` |
| 3 | 正解 | `答え。解説…` |

- 2・3列目は **最初の「。」より前が答え**、後ろが解説として扱われます（解説は省略可）。
- 欄の中に半角カンマ `,` を含めるときは、その欄全体を `"..."` で囲みます。`"` 自体を書くときは `""` と重ねます。

```csv
上から読んでも下から読んでも同じ、赤い野菜はなーに？,トマト。回文になっています。,トマト。トマトは英語でも同じ発音です。
空をとぶ「き」は？,飛行機。…,"ひこうき。高度約10,000mを飛ぶそうです。"
```

### 正解の書き方のコツ

- 答えは **ひらがな・カタカナ** で書くと、入力が一致しやすくなります。
- 別の言い方も正解にしたいときは括弧で併記します：`いぬ（犬）`、`きゅう（9）`、`シャツ（セーター）`
  → 括弧の外（`いぬ`）・中（`犬`）のどちらを入力しても正解になります。
- 文章で答える問題（例：「かごごとわたしたから」）は一致しにくいですが、その場合はユーザーが自分で正誤を判定します。

### AIの答え

- AI が「それっぽく間違える」のがアプリの面白さなので、基本は不正解にします。
- AIの答えが正解と一致すると「AIも正解」と表示され、結果画面の AI の点数に加算されます。一致の判定はユーザーの答えと同じルール（下記）です。

## 2. 答えの判定ルール（`AnswerMatcher`）

入力と正解を次のように正規化してから比較します。

1. 全角英数字 → 半角、半角カナ → 全角（Unicode NFKC）
2. 英字を小文字に
3. カタカナ → ひらがな
4. 空白・句読点・記号・「〜」を削除（**長音「ー」は残す**）

正解側は「全体」「括弧を除いたもの」「括弧の中身」をそれぞれ正解候補にします。入力側は「全体」「括弧を除いたもの」で比較します。

| 入力 | 正解 | 判定 |
| --- | --- | --- |
| ニンゲン | にんげん | ○ |
| 焼き鳥屋 | やきとりや（焼き鳥屋） | ○ |
| こーら | コーラ | ○ |
| こら | コーラ | ×（長音の有無） |
| かわ | つりかわ | ×（部分一致は不可） |

## 3. データベース（SQLite）

- ファイル：アプリの Documents ディレクトリ `db.sqlite3`
- テーブル `Riddles`

| カラム | 型 | 説明 |
| --- | --- | --- |
| id | INTEGER PRIMARY KEY AUTOINCREMENT | 問題ID |
| question | TEXT | 問題文（CSVとの突き合わせキー） |
| aiAnswer | TEXT | AIの答え（CSV 2列目そのまま） |
| trueAnswer | TEXT | 正解（CSV 3列目そのまま） |

### CSV との同期（`RiddleRepository.sync(with:)`）

起動のたびに 1 トランザクションで実行します。

1. CSV 内で問題文が重複していたら **先に出てきた行** を採用
2. CSV にない問題文の行を **削除**
3. CSV の各問題について、DB に同じ問題文があれば答えを **更新**、なければ **追加**

CSV が読み込めなかった（0件の）場合は何もしません（DB を空にしないため）。

## 4. 端末に保存する設定・記録（UserDefaults）

| キー | 型 | 内容 |
| --- | --- | --- |
| `hasAgreedToTerms` | Bool | 利用規約に同意済みか |
| `playStats` | Data（`PlayStats` の JSON） | プレイ記録 |

`PlayStats` の中身：

| プロパティ | 内容 |
| --- | --- |
| `playCount` | 最後まで遊んだゲーム数（途中でやめた回は含まない） |
| `answeredCount` | 出題された問題数の合計 |
| `correctCount` | 正解数の合計（正答率 = correctCount / answeredCount） |
| `winsAgainstAI` | AI より正解数が多かったゲーム数 |
| `bestScores` | コースID（`quick` / `standard` / `challenge`）→ ベストの正解数 |

`PlayStats` に項目を追加するときは、古いデータを読めるように **デフォルト値を持たせ**、`Codable` のデコードが失敗しないようにしてください（失敗すると記録がリセットされます）。
